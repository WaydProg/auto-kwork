# auto-kwork

Telegram-бот для мониторинга новых проектов на бирже Kwork с уведомлениями и отправкой откликов через Selenium.

## Установка

```bash
python3.14 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS, KWORK_EMAIL, KWORK_PASSWORD
```

Нужен установленный Google Chrome. Версия определяется автоматически. Если chromedriver не запускается (`session not created`), укажите `CHROME_VERSION_MAIN` — мажорную версию Chrome из `chrome://version`.

## Авторизация на Kwork

Сессия хранится в отдельном профиле Chrome (`CHROME_PROFILE_DIR`, по умолчанию `./chrome_profile`), так что входить нужно один раз.

- **Автоматически:** при `/start_work` бот входит по `KWORK_EMAIL`/`KWORK_PASSWORD`.
- **Вручную** (если Kwork показывает капчу или просит код):
  ```bash
  python parser.py --login
  ```
  Откроется окно Chrome: войдите в аккаунт и нажмите Enter в терминале. Бот в это время должен быть остановлен, потому что Chrome не может открыть один профиль дважды.

Без авторизации мониторинг работает, но вложенные файлы не скачиваются (Kwork отдаёт их только авторизованным пользователям, поэтому в сообщении будут ссылки), а отклики не отправляются.

## Запуск

```bash
python bot.py
```

| Команда | Действие |
|---|---|
| `/start_work` (или `/start-work`) | запустить фоновый мониторинг; уведомления приходят в чат, где вызвана команда |
| `/stop_work` (или `/stop-work`, `/stop_kwork`, `/stop-kwork`) | остановить мониторинг и закрыть браузер |
| `/status` | состояние мониторинга |
| `/cancel` | отменить ввод отклика |

Telegram разрешает в командах только `a-z`, `0-9` и `_`, поэтому в меню бота показаны варианты с подчёркиванием. Если вручную набрать вариант с дефисом, он тоже сработает.

Отклик: нажмите «💬 Откликнуться» и отправьте текст. Цену и срок можно указать отдельными строками:
```
Здравствуйте! Сделаю за 2 дня...
Цена: 5000
Срок: 2
```
По умолчанию цена берётся из бюджета проекта, а срок из `OFFER_DEFAULT_DAYS`.

Статусы проекта в БД: `new` (сохранён, отправка в Telegram не удалась, будет повторена), `sent`, `ignored`, `responded`. Проекты со статусом `sent`, `ignored` или `responded` повторно не присылаются.

## Задержки и защита от блокировок

Все параметры задаются в `.env`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PARSE_INTERVAL_MIN` / `PARSE_INTERVAL_MAX` | 60 / 180 | пауза между циклами (сек); берётся случайное значение из диапазона |
| `PAGE_DELAY_MIN` / `PAGE_DELAY_MAX` | 2 / 5 | пауза между страницами пагинации |
| `MAX_PAGES` | 3 | сколько страниц листать за цикл. Пагинация прерывается раньше, если на странице нет новых проектов |
| `PAGE_LOAD_TIMEOUT` | 30 | таймаут загрузки страницы |
| `SEND_DELAY` | 1 | пауза между сообщениями в Telegram (лимит около 20 сообщений в минуту в один чат) |
| `HEADLESS` | 0 | запуск без окна. Headless-режим легче распознаётся как бот |

Рекомендации:
- **Не уменьшайте интервал меньше 60 секунд.** Новые проекты появляются на первой странице, а частые запросы с одного IP быстрее приводят к капче.
- **Используйте постоянный профиль (`CHROME_PROFILE_DIR`).** Он хранит cookies и историю, и живая сессия выглядит естественнее, чем каждый раз новый вход.
- **Работайте с видимым окном (`HEADLESS=0`).** Если бот работает на сервере без экрана, используйте `xvfb-run python bot.py` вместо headless.
- **Если появилась капча или страница блокировки,** бот пришлёт в чат «Ошибка парсинга», а скриншот сохранит в `logs/`. Остановите мониторинг, выполните `python parser.py --login`, пройдите проверку вручную и запустите мониторинг снова.
- **Не держите один аккаунт в нескольких браузерах одновременно.**
- Первый запуск пришлёт до `MAX_PAGES × 12` проектов. Если это слишком много, временно поставьте `MAX_PAGES=1`.

## Проверка парсера без бота

```bash
python parser.py   # печатает проекты с первой страницы
```
